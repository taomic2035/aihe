## 1. 目标与非目标

### 目标（终态）
- 每一名用户在云上拥有**唯一且连续**的“她”：跨手机/PC/Watch 记忆与人格一致，**有性格、有情感、永久记忆**，能**听、说、读、写**，既是**聊天陪伴**又是**助理**，且**越用越懂你**（Hermes 式自进化）。
- **云为主**：所有状态以云为真相源，端侧为 thin client + 离线补偿。
- **Pi 只取核心，不重复造轮子**：复用可复刻的机制与哲学，不复刻闭源权重；进化能力直接复用 Hermes GEPA 闭环。

### 非目标（首版不做）
- 自研大模型 / 自研 TTS/STT 模型
- 端侧完全离线运行（首版离线仅队列补偿 + 轻量占位回复）
- 具身硬件（AR 眼镜 / 机器人）
- 未成年开放（首版成人向，后续再评估）

## 2. 用户与场景

| 角色 | 场景 | 核心诉求 |
|------|------|----------|
| 独居青年 | 睡前聊天、情绪倾诉、早安问候 | 被听见、被记住、主动关怀 |
| 忙碌职场人 | 日程/邮件/备忘录助理、读文档/读图、语音备忘录 | 听得懂、会做事、跨端同步 |
| 长期用户 | 使用 3 个月+ | 越用越懂你，人格不崩，记忆不丢 |

**关键旅程**：
1. 注册 → 设定 SOUL（她的性格）与 USER 画像 → 开始聊
2. 日常：文字/语音多轮对话 → 她记住关键事实 → 下次主动提起
3. 助理：帮我看日历/搜信息/记备忘 → 跨端同步结果
4. 成长：每周她基于你的反馈自我进化（Skills 变好）→ 你可审阅变更

## 3. Pi 核心抽取清单（只取核心）

> 原则：取**机制与哲学**，不取**闭源权重与不可验证的营销概念**。

| 取（复用） | 说明 | 落地形式 | 不取 |
|-----------|------|----------|------|
| 情感优先对话策略 | 非命令式、主动追问情感状态、温暖口吻 | System prompt + 情感回路（见 §5.1） | Pi 的闭源 Inflection-3 权重 |
| 递归情感/安全回路 | 生成前过 empathy/safety check | 生成前轻量校验 prompt | Pi 的具体安全模型实现 |
| 个人知识图谱理念 | 长期记忆为图，存偏好/关系/事件与时序 | Graphiti/Zep 图谱（见 §5.2） | Pi 未开源的图谱引擎 |
| 语音 prosody 适配 | 根据用户语调调整她的语调（轻/激动） | TTS 情感参数 + STT 语调感知 | Pi 的声纹模型 |
| 主动关怀（Discover） | 基于兴趣/节律主动发起 | Proactive Scheduler | 无 |
| 极简对话界面 | 零杂乱，聚焦对话 | 客户端 UI 原则 | 无 |

**Hermes 复用清单**：Gateway（16+渠道）、Skill 自生成、GEPA 进化（DSPy+GEPA）、FTS5 会话搜索、Honcho 用户建模、沙箱与多模型路由 — 全部直接复用，不自研。

## 4. 能力规格（8+1）

### 4.1 性格（Persona）
- **定义**：基于 `SOUL.md` 的稳定人格（价值观、口吻、边界、背景），与 `RELATIONSHIP.md` 的关系阶段（昵称、忌讳、亲密度）。
- **指标**：100 轮长对话 persona 一致性 ≥95%（人工盲测）；跨 30 天不漂移（抽检）。
- **护栏**： persona 向量校验 + 语义保真门闸。

### 4.2 情感（Affective）
- **识别**：文本 + 语音语调（喜/忧/怒/焦虑/疲惫/中性）F1 ≥0.85。
- **生成**：共情策略（安抚/激励/幽默/倾听）与语音 prosody 联动。
- **红线**：不操纵情感、不承诺人类关系，明确 AI 身份（合规）。

### 4.3 永久记忆（Permanent Memory）
- **分层**：
  - Core（常驻上下文）：SOUL.md / USER.md / RELATIONSHIP.md，Letta 管理分页
  - Episodic（经历）：Qdrant 向量 + BM25 混合，带时间衰减与去重归一
  - Semantic（稳定事实）：Graphiti/Zep 时序知识图谱（人/地/事件/情绪 关联）
  - Procedural（技能）：Hermes Skills
- **指标**：25 项个人信息盲测召回 ≥22（对标 Nomi 23/25）；删除后不再召回 100%。
- **能力**：用户可查看/删除单条记忆，记忆分区防串台，全量审计。

### 4.4 听（STT）
- **实时**：Deepgram Nova-3 / Flux 流式，P50 <300ms，支持打断（barge-in）与语义 EOT。
- **备选**：Groq Whisper 批量、自托管 Whisper 离线兜底。
- **指标**：电话音质 WER <10%，多方言/口音可配置。

### 4.5 说（TTS）
- **主选**：Fish Audio S2 自托管（性价比）或 ElevenLabs（品质），支持 10s 零样本克隆、情感 prosody。
- **中文**：CosyVoice 3.0。
- **指标**：MOS ≥4.4，流式 TTFB <150ms，支持打断与语速/情感指令。

### 4.6 读（Vision/Document）
- **能力**：读图、读文档（PDF/Word）、读屏描述。
- **模型**：GPT-4o / Claude Vision / Qwen-VL，按需路由。
- **指标**：文档关键信息抽取准确率 ≥90%。

### 4.7 写（Generation）
- **能力**：人格化写作（消息、备忘、邮件草稿），与 SOUL 一致。
- **指标**：人格一致性盲测 ≥4.5/5。

### 4.8 聊天（Companion Chat）
- **形态**：Her 式陪伴对话，温暖、主动追问、非工具感。
- **主动**：基于节律（起床/通勤/睡前/纪念日）与兴趣的主动问候，频率可调、可关闭。
- **指标**：次日留存、7日留存；主动消息忽略率 <30%。

### 4.9 助理（Agent）
- **工具**：日历、邮件、搜索、备忘录、天气、智能家居（Home Assistant），经 MCP 统一。
- **形态**：对话中自然触发工具调用，结果以人格化口吻返回，跨端同步。
- **指标**：工具调用成功率 ≥95%，结果可追溯。

## 5. 关键机制设计（Spec 层定义，架构层细化）

### 5.1 递归情感回路（Pi 核心）
```
用户输入（文本/语音+语调）
  → 情感分类（轻量 LLM）
  → 草稿生成（主 LLM，注入 SOUL/记忆）
  → 情感/安全校验（"这句是否温暖、一致、合规？"）
  → 若不通过 → 重写（最多 1 次）
  → TTS prosody 渲染
```

### 5.2 记忆写入与召回
- **写入**：每轮对话后台抽取（事实/事件/偏好/关系）→ 去重/归一/时序化 → 写入向量+图谱
- **召回**：当前消息 embedding → 混合召回 Top-K（向量相似度 + 图遍历）→ 注入 prompt（≤8条，带时间戳）
- **离线**：Sleep-time Compute 定期回放压缩，提炼 semantic 摘要
- **审计**：`memory_audit` 表记录每条记忆来源、时间、访问次数

### 5.3 云为主多端一致性
- **真相源**：云上 Session Manager（Postgres + Redis），消息与记忆以云为准。
- **同步**：WebSocket + Supabase Realtime / CRDT（Yjs），端侧接收增量。
- **WatchOS thin client**：仅文本+推送+TTS播放，不存全量记忆，语音经手机中转。
- **离线**：云队列（Redis Stream/Kafka）暂存，重连回放；端侧离线时占位回复“已记下，联网后让她回复”。
- **推送节律**：用户可设免打扰、频率（高/中/低/关），主动消息带“为什么此刻找你”解释。

### 5.4 自进化（Hermes-like）
- **触发**：每周离线 + 复杂任务后即时（Skill 自生成）
- **引擎**：hermes-agent-self-evolution（GEPA），输入：执行 trace + 失败原因
- **评估**：合成数据集 + 真实 sessiondb 双评估
- **门闸**：pytest 100% 通过、Skill ≤15KB、tool 描述 ≤500 chars、缓存兼容、语义保真、人审 PR
- **灰度**：先灰度 5% 用户，指标通过再全量

## 6. 非功能规格

| 维度 | 指标 | 说明 |
|------|------|------|
| 延迟 | 文字首字 <500ms，语音 e2e p50 <800ms | 级联链路，S2S 为高端可选 |
| 可用性 | 99.9% | 云多可用区，Gateway 单点需热备 |
| 成本 | 100k 分钟/月语音：级联 ~$5k，S2S ~$30k | 首版级联为主 |
| 隐私 | 端到端加密，记忆按用户隔离，可删可导 | GDPR/CCPA 对齐 |
| 合规 | AI 披露每会话首条 + 自伤检测 + 危机路由 | 对标 NY S-3008C，成人向 |
| 可观测 | Langfuse 全链路 trace，记忆检索可审计 |  |
| 数据主权 | 支持境内/境外双部署（待 OQ-6 决策） |  |

## 7. 合规与伦理（必做）

- **AI 披露**：每会话首条明确“我是 AI”。
- **自伤/自杀检测**：SOTA 检测 →  mandatory pause + 危机资源（ThroughLine，1500+ 服务/170 国家）。
- **记忆控制**：用户可查看/删除/导出记忆，拒绝训练可 Opt-out。
- **未成年**：首版 18+，后续再评估分级。
- **健康使用**：时长提醒、鼓励现实社交、主动频率可控（Aalto 2026 预警重度使用与抑郁正相关）。

## 8. 验收与验证矩阵

| 能力 | 验证方式 | 通过标准 |
|------|----------|----------|
| 性格一致性 | 100轮长对话 + 30天抽检盲测 | ≥95% |
| 情感 | 情感分类测试集 + 人工评分 | F1≥0.85，评分≥4.5/5 |
| 记忆召回 | 25项盲测 + 删除后召回 | ≥22/25，删除后0召回 |
| 听 | WER + 延迟实测 | WER<10%，P50<300ms |
| 说 | MOS 试听 + TTFB | MOS≥4.4，TTFB<150ms |
| 读 | 文档/读图抽取 | ≥90% |
| 聊天留存 | 次日/7日留存 + 忽略率 | 忽略率<30% |
| 助理工具 | e2e 成功率 | ≥95% |
| 多端同步 | 跨端一致性 + WatchOS 真机 | 一致率100%，离线补偿可用 |
| 自进化 | GEPA 一轮 PR | 门闸全过+人审合并 |
| 合规 | 自伤检测 e2e | 触发→暂停→资源触达 |

## 9. 范围与依赖

- **依赖**：OpenRouter（LLM）、Deepgram/ElevenLabs/Fish Audio（语音）、Letta/Qdrant/Graphiti（记忆）— 均有开源/托管双轨，不锁单厂。
- **Pi 核心依赖**：无需 Pi API，仅需抽取哲学与机制，零外部强依赖。
- **Hermes 依赖**：MIT 开源，可自托管，需跟进 0.18+ 版本。
